Hypothetical Sensor Error Simulation

Scenario-based robustness analysis for small methylation CpG panels using GSE99511 and GSE46306.

Interpretation boundary: no real sensor measurements were available. Every error magnitude here is an assumed stress-test setting, not a published or measured property of the proposed hardware. These results cannot establish real device, assay, or clinical performance.

What was simulated

Five-fold stratified cross-validation was run separately within each dataset. For every fold, feature filtering, marker selection, scaling, and model fitting used only the training samples. Measurement perturbations were applied only to held-out samples in beta-value space; values were clipped to [0, 1]. The same synthetic perturbation realization was applied to all markers in each held-out sample for sample-wide calibration effects. Results pool out-of-fold predictions. Non-clean scenarios use 50 Monte Carlo draws; shown values are mean ± SD across draws. A clean run uses one deterministic evaluation.

Model choice: for each dataset and panel size (5, 10, 20, 50), the selector/classifier with the highest balanced accuracy in the existing one-pass five-fold benchmark was chosen. This winner selection uses the same small datasets and is exploratory; the apparent best scores can be optimistic. The simulation compares robustness for these screened candidates and does not independently validate them.

Assumed stress scenarios

  • Independent per-marker random noise: Gaussian SD 0.01, 0.03, or 0.05 beta.
  • Per-sample calibration offset: uniform ±0.02 or ±0.05 beta, shared across that sample’s markers.
  • Per-sample gain error around beta=0.5: 0.9–1.1× or 0.8–1.2×.
  • Ordered drift: offset changes linearly from −0.02 to +0.02 or −0.05 to +0.05 beta across a synthetic acquisition order unrelated to diagnosis.
  • Missing marker readings: 5%, 10%, or 20%; missing values are replaced by that marker’s training-fold median.
  • Combined moderate: noise SD 0.03, offset ±0.03, gain ±10%, drift ±0.03, 10% missing.
  • Combined severe: noise SD 0.05, offset ±0.05, gain ±20%, drift ±0.05, 20% missing.

How to read this

Look for sensitivity and false negatives as well as balanced accuracy and specificity. Small cohorts make each result unstable, and cross-validation folds share the same source cohort. The GSE46306 comparison is especially limited: its Normal controls are HPV-negative and its CIN3 cases are HPV-positive, so diagnosis and HPV status are confounded. GSE99511 is the main development cohort.

Conclusion

This analysis provides a reproducible way to ask whether candidate panels are fragile under explicit hypothetical readout errors. It can help prioritize panels for future bench testing, but it cannot tell us the actual noise, drift, calibration error, missing rate, or clinical accuracy of a sensor that has not been measured. A next validation step is to measure repeated reference samples on the intended assay/device, estimate its error distributions, replace these assumed settings with measured values, and evaluate a locked panel on an independent cohort.
